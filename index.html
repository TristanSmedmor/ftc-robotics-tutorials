Mecanum Wheel OnBotJava Guide

STEP 1

Physical Wheel Mounting & Roller Configuration

Verify physical installation before writing code. Mecanum wheels feature 45-degree angled rollers that generate lateral forces when rotated.

  • Top View ("X" Pattern): Looking from directly above, the top rollers contacting the carpet MUST form an "X" shape across the chassis.
  • Bottom View ("O" Pattern): Looking up from under the robot, bottom rollers form an "O". If the top view forms an "O", swap left and right wheels immediately.

STEP 3

Kinematics Equations & Power Normalization

Wheel powers combine axial vector (Y), lateral vector (X), and rotational vector (RX):

  • Front Left = Y + X + RX
  • Back Left = Y - X + RX
  • Front Right = Y - X - RX
  • Back Right = Y + X - RX

Power Normalization: If combined inputs exceed 1.0 (e.g. 1.5), divide all four motor powers by the maximum absolute output to preserve steering ratios.

STEP 4

Robot-Centric TeleOp Code & Line-by-Line Guide

package org.firstinspires.ftc.teamcode;

import com.qualcomm.robotcore.eventloop.opmode.LinearOpMode;
import com.qualcomm.robotcore.eventloop.opmode.TeleOp;
import com.qualcomm.robotcore.hardware.DcMotor;
import com.qualcomm.robotcore.hardware.DcMotorSimple;

@TeleOp(name = "Mecanum Robot-Centric", group = "Linear OpMode")
public class MecanumTeleOpRobotCentric extends LinearOpMode {

    @Override
    public void runOpMode() throws InterruptedException {
        // Line A1: Fetch hardware objects from Driver Station configuration
        DcMotor frontLeftMotor = hardwareMap.get(DcMotor.class, "frontLeft");
        DcMotor backLeftMotor = hardwareMap.get(DcMotor.class, "backLeft");
        DcMotor frontRightMotor = hardwareMap.get(DcMotor.class, "frontRight");
        DcMotor backRightMotor = hardwareMap.get(DcMotor.class, "backRight");

        // Line A2: Reverse left motors for forward drive alignment
        frontLeftMotor.setDirection(DcMotorSimple.Direction.REVERSE);
        backLeftMotor.setDirection(DcMotorSimple.Direction.REVERSE);
        frontRightMotor.setDirection(DcMotorSimple.Direction.FORWARD);
        backRightMotor.setDirection(DcMotorSimple.Direction.FORWARD);

        // Line A3: Enable active BRAKE mode on zero power
        frontLeftMotor.setZeroPowerBehavior(DcMotor.ZeroPowerBehavior.BRAKE);
        backLeftMotor.setZeroPowerBehavior(DcMotor.ZeroPowerBehavior.BRAKE);
        frontRightMotor.setZeroPowerBehavior(DcMotor.ZeroPowerBehavior.BRAKE);
        backRightMotor.setZeroPowerBehavior(DcMotor.ZeroPowerBehavior.BRAKE);

        waitForStart();

        while (opModeIsActive()) {
            // Line A4: Read gamepad sticks (Y is inverted natively by Android)
            double y = -gamepad1.left_stick_y;
            double x = gamepad1.left_stick_x * 1.1; // 1.1x friction multiplier
            double rx = gamepad1.right_stick_x;

            // Line A5: Compute raw kinematics power values
            double frontLeftPower = y + x + rx;
            double backLeftPower = y - x + rx;
            double frontRightPower = y - x - rx;
            double backRightPower = y + x - rx;

            // Line A6: Proportional power normalization
            double maxPower = Math.max(Math.abs(frontLeftPower), Math.abs(backLeftPower));
            maxPower = Math.max(maxPower, Math.abs(frontRightPower));
            maxPower = Math.max(maxPower, Math.abs(backRightPower));

            if (maxPower > 1.0) {
                frontLeftPower /= maxPower;
                backLeftPower /= maxPower;
                frontRightPower /= maxPower;
                backRightPower /= maxPower;
            }

            // Line A7: Send power commands to motor controllers
            frontLeftMotor.setPower(frontLeftPower);
            backLeftMotor.setPower(backLeftPower);
            frontRightMotor.setPower(frontRightPower);
            backRightMotor.setPower(backRightPower);
        }
    }
}

STEP 5

Field-Centric TeleOp & IMU Integration

Uses the REV Control Hub gyro so pushing UP moves toward the far wall regardless of robot rotation.

package org.firstinspires.ftc.teamcode;

import com.qualcomm.robotcore.eventloop.opmode.LinearOpMode;
import com.qualcomm.robotcore.eventloop.opmode.TeleOp;
import com.qualcomm.robotcore.hardware.DcMotor;
import com.qualcomm.robotcore.hardware.DcMotorSimple;
import com.qualcomm.hardware.rev.RevHubOrientationOnRobot;
import com.qualcomm.robotcore.hardware.IMU;
import org.firstinspires.ftc.robotcore.external.navigation.AngleUnit;

@TeleOp(name = "Mecanum Field-Centric", group = "Linear OpMode")
public class MecanumTeleOpFieldCentric extends LinearOpMode {

    @Override
    public void runOpMode() throws InterruptedException {
        DcMotor frontLeftMotor = hardwareMap.get(DcMotor.class, "frontLeft");
        DcMotor backLeftMotor = hardwareMap.get(DcMotor.class, "backLeft");
        DcMotor frontRightMotor = hardwareMap.get(DcMotor.class, "frontRight");
        DcMotor backRightMotor = hardwareMap.get(DcMotor.class, "backRight");

        frontLeftMotor.setDirection(DcMotorSimple.Direction.REVERSE);
        backLeftMotor.setDirection(DcMotorSimple.Direction.REVERSE);

        // Line B1: Fetch and initialize REV Hub IMU orientation
        IMU imu = hardwareMap.get(IMU.class, "imu");
        IMU.Parameters parameters = new IMU.Parameters(new RevHubOrientationOnRobot(
                RevHubOrientationOnRobot.LogoFacingDirection.UP,
                RevHubOrientationOnRobot.UsbFacingDirection.FORWARD));
        imu.initialize(parameters);

        waitForStart();

        while (opModeIsActive()) {
            double y = -gamepad1.left_stick_y;
            double x = gamepad1.left_stick_x * 1.1;
            double rx = gamepad1.right_stick_x;

            // Line B2: Reset heading zero reference when pressing Options/Start
            if (gamepad1.options || gamepad1.start) {
                imu.resetYaw();
            }

            // Line B3: Read robot heading angle in radians
            double botHeading = imu.getRobotYawPitchRollAngles().getYaw(AngleUnit.RADIANS);

            // Line B4: Apply 2D inverse rotation matrix
            double rotX = x * Math.cos(-botHeading) - y * Math.sin(-botHeading);
            double rotY = x * Math.sin(-botHeading) + y * Math.cos(-botHeading);

            // Line B5: Compute field-relative motor powers
            double frontLeftPower = rotY + rotX + rx;
            double backLeftPower = rotY - rotX + rx;
            double frontRightPower = rotY - rotX - rx;
            double backRightPower = rotY + rotX - rx;

            // Power normalization
            double maxPower = Math.max(Math.abs(frontLeftPower), Math.abs(backLeftPower));
            maxPower = Math.max(maxPower, Math.abs(frontRightPower));
            maxPower = Math.max(maxPower, Math.abs(backRightPower));

            if (maxPower > 1.0) {
                frontLeftPower /= maxPower;
                backLeftPower /= maxPower;
                frontRightPower /= maxPower;
                backRightPower /= maxPower;
            }

            frontLeftMotor.setPower(frontLeftPower);
            backLeftMotor.setPower(backLeftPower);
            frontRightMotor.setPower(frontRightPower);
            backRightMotor.setPower(backRightPower);
        }
    }
}
STEP 6

Autonomous Encoder Driving Guide

Convert distance in inches to motor encoder ticks using wheel diameter and gear ratios.

package org.firstinspires.ftc.teamcode;

import com.qualcomm.robotcore.eventloop.opmode.Autonomous;
import com.qualcomm.robotcore.eventloop.opmode.LinearOpMode;
import com.qualcomm.robotcore.hardware.DcMotor;
import com.qualcomm.robotcore.hardware.DcMotorSimple;

@Autonomous(name = "Mecanum Auto Encoder", group = "Linear OpMode")
public class MecanumAutoEncoder extends LinearOpMode {

    private DcMotor frontLeftMotor, backLeftMotor, frontRightMotor, backRightMotor;
    
    // Ticks per revolution calculation for 537.7 ticks/rev motor & 96mm wheels
    static final double COUNTS_PER_MOTOR_REV = 537.7;
    static final double WHEEL_DIAMETER_INCHES = 3.77953;
    static final double COUNTS_PER_INCH = COUNTS_PER_MOTOR_REV / (WHEEL_DIAMETER_INCHES * Math.PI);

    @Override
    public void runOpMode() throws InterruptedException {
        frontLeftMotor = hardwareMap.get(DcMotor.class, "frontLeft");
        backLeftMotor = hardwareMap.get(DcMotor.class, "backLeft");
        frontRightMotor = hardwareMap.get(DcMotor.class, "frontRight");
        backRightMotor = hardwareMap.get(DcMotor.class, "backRight");

        frontLeftMotor.setDirection(DcMotorSimple.Direction.REVERSE);
        backLeftMotor.setDirection(DcMotorSimple.Direction.REVERSE);

        setRunMode(DcMotor.RunMode.STOP_AND_RESET_ENCODER);
        setRunMode(DcMotor.RunMode.RUN_USING_ENCODER);

        waitForStart();

        // Drive Forward 24 inches
        encoderDrive(0.5, 24, 24, 24, 24, 4.0);
        // Strafe Right 12 inches
        encoderDrive(0.5, 12, -12, -12, 12, 3.0);
    }

    public void encoderDrive(double speed, double flInches, double blInches, double frInches, double brInches, double timeoutS) {
        if (opModeIsActive()) {
            int newFLTarget = frontLeftMotor.getCurrentPosition() + (int)(flInches * COUNTS_PER_INCH);
            int newBLTarget = backLeftMotor.getCurrentPosition() + (int)(blInches * COUNTS_PER_INCH);
            int newFRTarget = frontRightMotor.getCurrentPosition() + (int)(frInches * COUNTS_PER_INCH);
            int newBRTarget = backRightMotor.getCurrentPosition() + (int)(brInches * COUNTS_PER_INCH);

            frontLeftMotor.setTargetPosition(newFLTarget);
            backLeftMotor.setTargetPosition(newBLTarget);
            frontRightMotor.setTargetPosition(newFRTarget);
            backRightMotor.setTargetPosition(newBRTarget);

            setRunMode(DcMotor.RunMode.RUN_TO_POSITION);

            frontLeftMotor.setPower(Math.abs(speed));
            backLeftMotor.setPower(Math.abs(speed));
            frontRightMotor.setPower(Math.abs(speed));
            backRightMotor.setPower(Math.abs(speed));

            while (opModeIsActive() && (frontLeftMotor.isBusy() && backLeftMotor.isBusy() && frontRightMotor.isBusy() && backRightMotor.isBusy())) {
                telemetry.addData("Target Pos", "FL:%d BL:%d FR:%d BR:%d", newFLTarget, newBLTarget, newFRTarget, newBRTarget);
                telemetry.update();
            }

            frontLeftMotor.setPower(0);
            backLeftMotor.setPower(0);
            frontRightMotor.setPower(0);
            backRightMotor.setPower(0);

            setRunMode(DcMotor.RunMode.RUN_USING_ENCODER);
        }
    }

    private void setRunMode(DcMotor.RunMode mode) {
        frontLeftMotor.setMode(mode);
        backLeftMotor.setMode(mode);
        frontRightMotor.setMode(mode);
        backRightMotor.setMode(mode);
    }
}

SymptomUnderlying CauseStep-by-Step Fix
Robot spins when trying to strafeIncorrect wheel placement or inverted motor sign.Verify top rollers form an "X" pattern and set left motors to REVERSE.
Strafing direction is reversedInverted X vector sign.In TeleOp code, change left_stick_x to -left_stick_x.
Robot drifts diagonally when driving straightUneven center of mass or roller friction variance.Rebalance weight distribution or implement IMU heading PID stabilization.
Motors coast after releasing sticksMotors left on default float mode.Set setZeroPowerBehavior(BRAKE) for all four motors.
